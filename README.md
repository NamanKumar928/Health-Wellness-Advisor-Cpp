# Health & Wellness Advisor (Dadi-Nani ke Nuskhe)

## 📌 Project Overview
This is a C++ based console application developed as part of SDF-II lab.

The project provides home remedies for common health issues using traditional knowledge combined with modern programming concepts.

## 🚀 Features
- User Login & Signup (File Handling)
- General Health Remedies
- Digestive System Remedies
- Scalp Care Analyzer
- Skin Care System (Linked List Implementation)
- Period Tracker
- Pain & Wound Remedies

## 🧠 OOP Concepts Used
- Inheritance
- Polymorphism
- Abstraction
- Encapsulation

## 🛠 Technologies Used
- C++
- File Handling
- Data Structures (Linked List)
